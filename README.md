🖼️ AI Image Editor

Консольный редактор изображений с обработкой через локальную нейросеть. Вы выбираете действие в меню — нейросеть определяет параметры и применяет обработку.


Возможности

Поворот
Любой угол от 0 до 360°. Готовые варианты: 30, 45, 60, 90, 120, 135, 150, 180, 270 градусов — или свой угол вручную.

Чёрно-белый
Пять художественных стилей:


Обычный — стандартный grayscale
Высококонтрастный — резкие тени и света (CLAHE)
Мягкий — мягкие тона, как на старой плёнке
Kodak T-MAX — имитация плёнки с зерновым шумом
Инфракрасный — небо тёмное, листья и кожа светлые


Зеркальное отражение
По горизонтали (лево↔право) или по вертикали (верх↔низ).

Размытие
Гауссово размытие трёх степеней: слабое, среднее, сильное.

Изменение размера
Готовые форматы: 320×240, 640×480, 800×600, 1280×720, 1920×1080 — или произвольный размер в пикселях.

Сохранение
Результат записывается в result.jpg. Исходный файл остаётся нетронутым.


Как работает

Каждое действие из меню уходит в локальную нейросеть (LM Studio) через механизм tool calling. Нейросеть сама определяет нужную функцию и параметры — интернет не используется, всё работает на вашем компьютере.
