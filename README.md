# 🖼️ AI Image Editor

Консольный редактор изображений с обработкой через локальную нейросеть.  
Выбираете действие в меню — нейросеть определяет параметры и применяет обработку.

---

## ✨ Возможности

### 🔄 Поворот
Любой угол от 0 до 360°. Готовые варианты: 30, 45, 60, 90, 120, 135, 150, 180, 270° — или свой угол вручную.

### 🎞️ Чёрно-белый — 5 стилей
| Стиль | Описание |
|---|---|
| Обычный | Стандартный grayscale |
| Высококонтрастный | Резкие тени и света (CLAHE) |
| Мягкий | Мягкие тона, как на старой плёнке |
| Kodak T-MAX | Имитация плёнки с зерновым шумом |
| Инфракрасный | Небо тёмное, листья и кожа светлые |

### 🪞 Зеркальное отражение
По горизонтали (лево↔право) или по вертикали (верх↔низ).

### 💧 Размытие
Гауссово размытие трёх степеней — слабое, среднее, сильное.

### 📐 Изменение размера
Готовые форматы: `320×240` `640×480` `800×600` `1280×720` `1920×1080`  
Или произвольный размер в пикселях.

### 💾 Сохранение
Результат записывается в `result.jpg`. Исходный файл остаётся нетронутым.

---

## 🤖 Как работает

Каждое действие из меню уходит в локальную нейросеть через механизм **tool calling**.  
Нейросеть сама определяет нужную функцию и параметры.  
Интернет не используется — всё работает на вашем компьютере.
