# 🖼️ AI Image Editor

Редактор изображений с тёмным интерфейсом и обработкой через локальную нейросеть.

---

## ✨ Возможности

### 🔄 Поворот
Быстрые кнопки на 90°, 180°, 270° — или своё поле для любого угла от 0 до 360°.

### 🎞️ Чёрно-белый — 5 стилей
| Стиль | Описание |
|---|---|
| Обычный | Стандартный grayscale |
| Высококонтрастный | Резкие тени и света (CLAHE) |
| Мягкий | Мягкие тона, как на старой плёнке |
| Kodak T-MAX | Имитация плёнки с зерновым шумом |
| Инфракрасный | Небо тёмное, листья и кожа светлые |

### 🪞 Отражение
По горизонтали (лево↔право) или по вертикали (верх↔низ).

### 💧 Размытие
| Степень | Ядро |
|---|---|
| Слабое | 5 |
| Среднее | 15 |
| Сильное | 31 |

### 📐 Изменение размера
| Формат | Размер |
|---|---|
| Стандарт | 640 × 480 |
| HD | 1280 × 720 |
| Full HD | 1920 × 1080 |
| Portrait | 1080 × 1350 |
| Stories | 1080 × 1920 |

Или любой свой размер в пикселях.

### ↩ История действий
Кнопка **Отменить** откатывает каждый шаг назад.
Кнопка **Оригинал** возвращает исходное фото целиком.

### 💾 Сохранение
Поддерживает JPG, PNG, BMP. Оригинальный файл остаётся нетронутым.

---

## 🤖 Как работает

Каждое действие уходит в локальную нейросеть через **tool calling**.
Нейросеть определяет нужную функцию и параметры — без интернета, всё на вашем компьютере.
